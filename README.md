# Диплом

Новый проект с каркасом React + TypeScript + Vite на основе архитектуры `autobrief`, без его бизнес-логики и секретов.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

## Собранный фронтовский стенд с backend и БД

Для проверки **собранного сайта**, а не Vite dev server, нужен работающий Docker. Из корня проекта:

```bash
pnpm stand:auth
# Только если нужен прежний строгий режим локально:
SCAN_BROWSER_ALLOW_ALL_LOCAL_ACCOUNTS=false SCAN_BROWSER_ALLOWED_USER_IDS=your-32-character-account-id pnpm stand:auth
```

Зарегистрируйтесь на http://127.0.0.1:8080/register и откройте `/scans/new`. Только в этой локальной конфигурации каждый аккаунт с действующей сессией может запускать ограниченный image scan `library/alpine` (`secret` и `sbom`; CVE только при подключённой актуальной offline DB); анонимный доступ закрыт. Любой посетитель локального стенда может зарегистрироваться и запустить скан, поэтому не публикуйте стенд в сеть. В HTTPS/публичной конфигурации этот режим отключён: там по умолчанию нужен точный allowlist ID, а не email. Контейнеры `web`, API, worker и egress сохраняют аккаунты и задания в **разных** Docker volumes. Через отдельный cookie-bound `/api/v1/browser/scans` разрешён только реальный `library/alpine` (`secret` и `sbom`; `vuln` только при дополнительном подписанном offline DB release); вход без явного разрешения на scan не даёт прав. `/demo/scans` остаётся фикстурой, внутренний JWT API `/api/v1/scans` возвращает 404 снаружи. Стенд привязан к loopback, **не публичен**; публикация требует TLS, бэкапов и отдельной защиты от злоупотреблений (см. [server/deploy/README.md](server/deploy/README.md)). `Ctrl+C` останавливает контейнеры без удаления данных; текущие контейнеры проверяются через `docker ps --filter name=dip-auth-stand`.

## Проверить регистрацию и backend локально

После установки зависимостей запустите **одну** команду в корне `diplom`:

```bash
pnpm dev:auth
```

Откройте **именно** http://127.0.0.1:5173/register, придумайте свой email и пароль длиной не менее 12 символов; затем проверьте http://127.0.0.1:5173/account, выход и повторный вход на `/login`. `/demo/scans` доступен без аккаунта. `Ctrl+C` останавливает оба процесса. Нужны свободные порты 5173 и 3001; при занятых портах команда завершается с ошибкой, не переключаясь на другой адрес.

Скрипт запускает Vite и NestJS только на loopback, проксирует браузеру **лишь** `/api/v1/auth`, создаёт локальную базу `.local-auth/auth.sqlite` (игнорируется Git) и генерирует отдельный временный scan JWT secret в памяти. Учётные записи переживают перезапуск, cookie работает по `127.0.0.1` (при переходе на `localhost` сессия не переносится). Если требуется очистить свои стендовые аккаунты, остановите сервер и вручную удалите `.local-auth/` — это удалит все локальные регистрации. Не копируйте базу и пароли в репозиторий. Реальный запуск сканирования **не открыт**: аккаунт не заменяет авторизацию внутреннего scan API. Это только локальный режим проверки, не конфигурация публичного стенда. Подробности: [server/api/README.md](server/api/README.md).

`pnpm build` собирает клиентскую и административную страницы; `pnpm dev:admin` запускает отдельный режим сборки админки. Проверки: `pnpm typecheck`, `pnpm lint`, `pnpm test`.

Описание слоёв и каталогов: [docs/architecture/README.md](docs/architecture/README.md). Предметные требования к дипломному проекту пока не заданы.
