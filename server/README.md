# Backend (частичная fail-closed реализация)

NestJS + TypeScript: HTTP API, управление заданиями сканирования Docker-образов и контейнеров, нормализация результатов внешних сканеров, события прогресса и интеграция с LLM.

В `api/` добавлены NestJS scaffold с защищённым по умолчанию POST (401 без токена, 503 с токеном; **никогда не 202**) и автономный SQLite ledger с транзакционным outbox; см. `api/README.md`. В `security-lab/` — TLS fixture и изолированный scanner с тестами реального Trivy; см. `security-lab/README.md`. Это не рабочий backend image scan: resolver, worker, identity provider и сквозная безопасная цепочка ещё не подключены. Доступ к Docker Engine должен оставаться на стороне изолированного worker/адаптера и никогда не попадать в браузер. Конкретный состав сканеров и привилегий определяется утверждённой спецификацией.

Провайдер ИИ выбран: OpenRouter. Ключ для будущего серверного адаптера — переменная `OPENROUTER_API_KEY` в серверном окружении (локальный `server/.env.local` исключён из Git). Backend пока не загружает этот файл и не вызывает провайдера. Не переносить ключ в Vite-переменные, документацию, логи или трекер; модель и правила передачи данных ещё требуют решения.
