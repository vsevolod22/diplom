# DIP-TASK-22 — новая визуальная концепция

2026-09-28 пользователь отклонил спокойный вид консоли из `ui-redesign-decision-task-19.md` и попросил выразительный лендинг с анимациями. Предыдущее решение остаётся историей; новое направление — тёмная редакционная типографика, лаймовый/фиолетовый акценты, геометрическая графика, движение в промо-зонах и компактный контрастный интерфейс данных. Украшения не обозначают прогресс или безопасность образа. `/` показывает промо-страницу; `/demo/scans` — только вымышленные фикстуры; `/scans` объясняет отсутствие авторизованного browser ingress.

## Использованные компоненты и происхождение

- Локальные компоненты интерфейса `src/shared/ui/scan-primitives.tsx` — собственный код проекта, совместимый по структуре с shadcn-подходом «компоненты в приложении»; код shadcn/Magic UI registry **не копировался**, точного registry snapshot и SHA для такого импорта нет.
- Анимация hero: установленный `motion` **12.23.24** (`motion/react`); иконки — установленный `lucide-react` **0.546.0**. Фокус и фильтр деталей — установленный `@radix-ui/react-dialog` **1.1.15**. Версии получены из `pnpm list --depth 0`, новые пакеты не добавлены. Перед публичным распространением отдельно перепроверить license/notice установленного артефакта и транзитивных зависимостей: разрешение пользователя на дизайн не отменяет прав авторов.
- Никаких удалённых картинок, шрифтов или данных; геометрия нарисована CSS. Анимация отключается через `prefers-reduced-motion` и `useReducedMotion`; иллюстрация не единственный носитель информации.

## Проверка и границы

Chromium Playwright для 320/375/1280px: навигация, маркировка фикстур, отсутствие горизонтального переполнения и перекрытия строк заголовка, контраст выбранных пар, фокус мобильного фильтра. Fixture coverage не означает production проверку. Ручной screen-reader, Safari/Firefox, реальные ingress/SSE/CVE/SBOM и оценка производительности на маломощном устройстве не выполнены. По `du -sh dist/assets` baseline до этого этапа 428K, после нового лендинга с lazy-маршрутом 572K; размеры округлены и включают ассеты обоих entrypoints, не являются анализом initial transfer конкретного маршрута. `HomePage` и Motion выделены в lazy chunk (125.61 kB raw / 40.99 kB gzip по выводу Vite build); браузерный профайлинг на слабом устройстве не выполнен. Бесконечные marquee/декор при обычной настройке движения ставятся на паузу вне viewport через `useInView`.
