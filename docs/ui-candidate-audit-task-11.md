# DIP-TASK-11 — аудит RareUI и Canvas UI до подключения

Дата доступа к источникам: **2026-09-27**. Область: оценка кандидатов, **не** установка, копирование, браузерный тест или визуальная реализация `DIP-TASK-12`. Решение на текущем этапе: **не подключать ни один из двух источников; оставить обычный HTML и существующие shadcn/ui-примитивы**. Необязательный декор не блокирует P0. `fail` здесь означает «не допущено к использованию по обязательным условиям», а не доказанный дефект компонента.

## Основание и метод

- [ТЗ, строки 30–32 и 126–138](TZ.md): React 19/Vite/Tailwind 4, локальные shadcn/ui, единый дизайн-язык; выборочно проверять лицензию, совместимость, a11y, безопасность, производительность, размер; canvas только как необязательный эффект с HTML-fallback и reduced motion.
- В локальном [package.json](../package.json) заявлены `react: ^19.1.1`, `react-dom: ^19.1.1`, `tailwindcss: ^4.1.15`, `vite: ^7.1.7`; [components.json](../components.json) указывает TSX, CSS-переменные, `src/app/styles/index.css` и alias `@/shared/ui`. Это **только исходные условия приложения**, не результат проверки кандидатов в нём.
- Метод: открыть первичную страницу кандидата и лицензионный текст автора; сопоставить заявления со стеком и обязательными критериями. В проект не импортировался код, не исполнялись registry CLI, dependency audit, тесты браузера, screen reader или замеры бандла/мобильных устройств. Версии исходников кандидатов, immutable commit/теги и артефакты registry не зафиксированы; страницы прочитаны в текущем состоянии на дату выше и могут измениться. Никаких численных оценок JS/CPU/FPS здесь нет.
- Политика допуска: **любое обязательное «не проверено» = fail**. Чтобы изменить решение, проверить именно выбранную версию/файлы и условия их распространения, затем выполнить интеграционные и инструментальные проверки; заявления на сайте сами по себе не считаются тестами.
