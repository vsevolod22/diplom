**Реально импортировано в изолированный прототип:** адаптированный исходник Magic UI Blur Fade (`blur-fade.tsx`, точный URL/notice в [THIRD_PARTY_NOTICES](THIRD_PARTY_NOTICES.md)); непосредственно upstream Radix Tabs и Accordion из уже установленных пакетов; `motion/react` и Lucide. `BlurFade` не скрывает essential-текст при первом кадре (`initial=false`) и сразу показывает всё при reduced motion. Radix примитивы **не являются копиями shadcn/ui registry wrappers**. Magic UI upstream registry JSON не закреплён immutable commit/hash, поэтому **production reuse не согласован**, несмотря на наличие локального исходника и MIT notice. Ни Embla, ни Aceternity, ни Motion Primitives registry здесь не установлены; они остаются кандидатами из прежнего обзора. Дополнительных runtime-пакетов не добавляли.

`node docs/ui-concepts/task-27-react/check.mjs` запускает временный Vite-сервер и Chromium и закрывает их после проверки. Проверяются 18 сочетаний (3 варианта × 320/375/1280 × reduce/no-preference), путь list→form→separate sample report, disabled запуск/чат, фильтр без совпадений/сброс, Accordion, недоступность live и overflow/page errors. Это не screen-reader, touch, FPS, аудит лицензий транзитивных пакетов или функциональный production e2e. Тексты статуса, reasons и coverage остаются без раскрытия/анимации. Выбор конкретного A1/A2/A3 и допустимых эффектов остаётся за пользователем до работы над `DIP-TASK-25/26`.
