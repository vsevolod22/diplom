# Архитектура каркаса

Основа взята из структуры `autobrief`, но предметный код и конфигурация его окружений не перенесены.

- `src/app` — провайдеры и глобальные стили клиентского приложения.
- `src/pages` — страницы; `src/features` — независимые функции продукта (`ui`, `model`, `modules` добавляются по мере появления задач).
- `src/shared` — повторно используемые UI-элементы, HTTP-клиент, конфигурация, хуки, утилиты и ресурсы. Предметная логика сюда не помещается.
- `src/admin-app` — отдельная точка входа для административного интерфейса, со своими `app`, `pages`, `features`, `shared`.
- `tests-vite`, `tests-e2e` — места для модульных/интеграционных и браузерных тестов; Playwright-конфигурация появится вместе с первыми e2e-сценариями.
- `index.html` и `admin.html` — независимые входы Vite; обе страницы собираются командой `pnpm build`.

Библиотеки и зафиксированные версии взяты из `autobrief/package.json` и `pnpm-lock.yaml` для совместимости стека. Многие библиотеки относятся к будущим возможностям (редактор, медиа, OpenAPI и т. п.) и пока не импортируются. Не переносите внешние URL, токены, сертификаты или контракты API из `autobrief`: у нового продукта они должны быть своими.

Направление зависимостей: `app → pages → features → shared`. Общие части не импортируют слои выше; предметные модули общаются через публичные интерфейсы.
